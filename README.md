# StoreKit API

A production-grade e-commerce REST API built with Node.js + TypeScript.

## Tech Stack

| Layer | Technology |
|---|---|
| Runtime | Node.js 20+ |
| Language | TypeScript 5 |
| Framework | Express.js 4 |
| ORM | Prisma (Phase 3) |
| Database | PostgreSQL (Phase 3) |
| Cache | Redis (Phase 9) |
| Queue | BullMQ (Phase 10) |
| Auth | JWT + bcrypt (Phase 6) |
| Validation | Zod (Phase 5) |
| Testing | Vitest + Supertest (Phase 13) |
| Docs | Swagger/OpenAPI (Phase 12) |
| Deploy | Docker + Docker Compose (Phase 14) |

## Getting Started

### Prerequisites

- Node.js 20+
- npm 9+

### Setup

```bash
# 1. Clone the repo
git clone <repo-url>
cd storekit-api

# 2. Install dependencies
npm install

# 3. Set up environment variables
cp .env.example .env
# Edit .env with your values

# 4. Start the development server
npm run dev
```

The API will be running at `http://localhost:3000`

### Available Scripts

| Script | Command | Description |
|---|---|---|
| Development | `npm run dev` | Start server with hot reload (tsx watch) |
| Build | `npm run build` | Compile TypeScript → JavaScript |
| Production | `npm start` | Run compiled JavaScript |
| Lint | `npm run lint` | Check code with ESLint |
| Lint Fix | `npm run lint:fix` | Auto-fix ESLint issues |
| Format | `npm run format` | Format code with Prettier |

## Project Structure

```
storekit-api/
├── src/
│   ├── config/
│   │   └── env.ts          # Environment variable loading & validation
│   ├── app.ts              # Express app (middleware, routes) — no server start
│   └── server.ts           # Server entry point (starts listening)
├── dist/                   # Compiled output (gitignored, generated by tsc)
├── .env                    # Local env vars (gitignored)
├── .env.example            # Env var template (committed)
├── .eslintrc.json          # ESLint rules
├── .prettierrc             # Prettier formatting config
├── .gitignore
├── tsconfig.json           # TypeScript compiler config
└── package.json
```
